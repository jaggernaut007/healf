# Contributing

## Development Loop

1. Read PROGRESS and relevant docs.
2. Run scripts/init.sh.
3. Plan tasks in 30-50 minute units.
4. Implement with failing tests first.
5. Run review waves: test, review, docs.

## Standards

- Follow AGENTS and CLAUDE instructions.
- Prefer direct imports and small functions.
- Use real data in integration contexts.
- Verify new dependencies before installation.

## Completion

- Tests and lint must pass via tool output.
- Update docs when behavior changes.
- Update PROGRESS and feature_list before handoff.
