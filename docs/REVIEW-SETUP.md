# Review Setup

## Review Principle

Treat agent-authored changes with the same rigor as human-authored changes.

## Review Focus

- Bugs and behavioral regressions.
- Security vulnerabilities and dependency risk.
- Compatibility and performance impacts.
- Missing tests for changed behavior.

## Multi-Agent Pattern

1. Test writer validates behavior.
2. Code reviewer validates quality and risk.
3. Docs writer validates synchronization.

Return SHIP, ITERATE, or BLOCK with concrete rationale.
