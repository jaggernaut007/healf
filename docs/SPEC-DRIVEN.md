# Specification-Driven Development

## Why

Agent success increases when tasks are explicit and bounded.

## Requirements for Each Task

- Clear acceptance criteria.
- Files likely modified.
- Out-of-scope constraints.
- Verifiable test expectations.

## Task Horizon

Keep tasks in the 30-50 minute implementation window.

## Execution Pattern

1. Intent
2. Plan
3. Execute
4. Validate
5. Document
